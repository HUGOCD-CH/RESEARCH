Option 1 — Use Your Existing Chrome

If Chrome is already open with webmail.medtronic.com, this app can attach directly to it. No extra login required.

  1. Start Chrome with remote debugging enabled:
    chrome.exe --remote-debugging-port=9222
    (or double-click start_chrome.bat)
  2. Open webmail.medtronic.com and log in normally.
  3. Click the button below.
